# 委譲を行う時の条件

通常作業ではこのガイドを読まない。モデル選択・委譲の機能を使う依頼がある場合だけ参照する。各社の最新機能や推奨モデルを示す資料ではない。

利用可能な機能と、委譲の許可を先に確認する。上位モデルが使えると推測しない。委譲できなければ、同じ権限・入力の範囲で自分で作業を続けるか、人へ不足を示す。

渡す情報は、Task ID、目的、正確な入力、出力先、禁止操作、検収条件、判断不能時に返す情報だけにする。会話履歴全体を複製しない。

同一ファイルへの同時書込みを避け、結果の依存関係と統合方法を明示する。共有の管理表は同時編集しない。委譲先の出力を承認済み成果物とせず、検収してから通常の承認を通す。モデル変更で権限を増やさない。モデルの価格・品質・削減効果は、実測・確認なしに主張しない。
