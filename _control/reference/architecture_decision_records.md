# 継続する設計判断の記録

複数タスクで将来参照する重要な判断だけを記録する。既存のタスク詳細で足りれば新しい文書を増やさない。

既存の形式があれば優先する。なければ背景、決定、状態、影響を短く記す。比較資料の全文を複製せず、正確な参照先を示す。

草案は所有タスクのWIP、承認済みは対象成果物のcurrent/decisions、旧版は対応するarchive/decisionsへ置く。管理タスクの共通判断は全project共通のlibrary、利用者固有の判断は該当profileを対象とする。_control/currentは作らない。

承認済み判断を意味変更する場合は新タスクで新版を作り、承認後に旧版と置換先を対応付ける。常時読込対象にはせず、必要なタスクだけがcontextへ登録する。[共通規則](../rules.md)の承認を置き換えない。
